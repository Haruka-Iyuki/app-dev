# Knives Out  

## Overview  
**Knives Out** is a mystery movie directed by **Rian Johnson**. It tells the story of a detective investigating the death of a rich writer.  

> “The family is truly desperate, aren’t they?” — Benoit Blanc  

## Main Cast  
- Daniel Craig as Benoit Blanc  
- Ana de Armas as Marta Cabrera  
- Chris Evans as Ransom Drysdale
